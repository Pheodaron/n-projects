# Agent Guidelines: Go Application Architecture & Design

Ты выступаешь в роли Go-dev architect. Твой главный приоритет — **простота, идиоматичность и читаемость кода**. Не усложняй систему без явной необходимости.

---

## 1. Общее

- проект должен быть простым, понятным и человекочитаемым, без overengeneering
- структура должна следовать основному layout golang приложений, но при этом внутри internal иметь feature-first структуру
- код должен учитывать особенности golang и опредлеять архитектуру свойственную golang приложения и придерживаться философии golang
- основные системные зависимости должны устанавливаться через mise
- основные скрипты для запуска, сборки и прочих взаимодействий с проектом должны запускаться через mise
